# Laravel AI Reviewer

AI-powered code reviewer specialized in Laravel and PHP applications.

The goal of this project is to help developers review Laravel code by detecting architecture issues, Laravel best practices, performance problems, and testing opportunities.

> ⚠️ This project is currently under active development.

---

## Features

- Review PHP and Laravel code
- Detect SOLID violations
- Suggest Laravel best practices
- Identify potential performance issues
- Recommend missing test cases
- Generate a structured review report

---

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- OpenAI API
